# Contributing

Issues and pull requests are welcome.

- For larger changes, open an issue first to agree on the direction.
- Build and test instructions are in [README.md](README.md). Run at least `.\gradlew.bat testDebugUnitTest` before submitting.
- Add tests for new behavior and fixes. Keep TalkBack navigation, custom accessibility actions, and focus restoration working.
- Do not commit keystores, signing properties, API keys, tokens, or personal data.
- Contributions are licensed under this repository's [MIT License](LICENSE).
